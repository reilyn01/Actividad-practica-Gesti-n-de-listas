# Gestión de listas

Nombre : Reilyn Genex
## Descripción
Programa desarrollado en C# que permite  agregar, mostrar, buscar, modificar y eliminar elementos, además de calcular estadísticas y ordenar los datos.

## Capturas del programa en ejecución

### 1. Menú principal
Muestra las opciones disponibles para trabajar con las listas.

### 2. Agregar productos
Permite registrar nuevos productos y sus respectivos precios.

### 3. Mostrar productos y precios
Muestra los elementos almacenados en ambas listas.

### 4. Buscar productos y precios
Permite comprobar si un producto o precio se encuentra registrado.

### 5. Modificar productos y precios
Permite cambiar los nombres de los productos y sus precios mediante sus posiciones.

### 6. Eliminar productos
Permite eliminar un producto de la lista.

### 7. Mostrar estadísticas
Muestra la cantidad de productos, el precio mayor, el menor y el promedio.

### 8. Ordenar listas
Organiza los productos alfabéticamente y los precios de menor a mayor.
